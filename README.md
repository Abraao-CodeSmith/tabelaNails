# Jenyffer Araújo — Nails Designer

Site institucional e tabela de serviços de uma Nails Designer. Desenvolvido em HTML, CSS e JavaScript puro, sem frameworks.

---

## Estrutura do projeto

```
├── index.html          # Página principal
├── style.css           # Estilos
├── script.js           # Lógica e dados dos serviços
├── font/               # Fontes locais (Charlotte, Champagne & Limousines)
├── img/                # Imagens dos serviços e ícones
└── fotos/              # Fotos da galeria do espaço
```

---

## Tecnologias

- **HTML5** semântico
- **CSS3** — variáveis CSS, Grid, Flexbox, `clamp()`, animações com `IntersectionObserver`
- **JavaScript** puro (ES6+) — sem frameworks ou bibliotecas externas
- **Google Fonts** — Dynalight (títulos) + Josefin Sans (textos)

---

## Funcionalidades

- **Hero section** com nome da profissional
- **Seções de serviços** com animação de entrada/saída via `IntersectionObserver`
- **Categorias de serviços:**
  - Extensão Tip
  - Banho Gel
  - Acrílico
  - Manicure Moderna
  - Tratamentos Podais Premium
  - Estética e Design Facial
  - Serviços Adicionais
- **Toggle Aplicação / Manutenção** para categorias com dois tipos de preço
- **Toggle de preço** (ex: completo / individual)
- **Descrições expansíveis** por serviço
- **Galeria de fotos** do espaço com lightbox (modal)
- **Botão flutuante** de agendamento via WhatsApp
- **Menu hambúrguer** responsivo para mobile
- **Navbar** com scroll suave até cada seção
- **Layout responsivo** — desktop e mobile

## Fontes

- **Dynalight** — títulos principais e nomes de seções (Google Fonts)
- **Josefin Sans** — textos gerais, labels, botões (Google Fonts)
- **Charlotte Veronica Script** — fallback local para títulos
- **Champagne & Limousines** — fallback local para textos
